## Notify me (claude-notify)
I usually work in other windows. When you finish a milestone (a feature done, a long
test run green, a deploy finished) or you are blocked and need me, run the `notify`
skill: `~/.claude/skills/notify/scripts/notify.sh "<one line: what finished or what you need>" --subtitle "<project name>"`.
Only at real milestones, never after every step. If nothing shows up, rerun it with the
Bash sandbox disabled.
